# Validation on 18 November 2026

A new Python 3.11 virtual environment was created without system site packages. CPU PyTorch/torchvision were installed from the official CPU wheel index; the project and optional segmentation dependencies were installed through pip. `pip check` found no broken requirements. The exact package versions are in `requirements-cpu-lock.txt`.

All 25 tests passed in that environment. They cover fixed-vocabulary scoring, whole-worm sampling, disjoint calibration, frozen experiment counts, visual-condition definitions, protected outputs, missing species targets, global metadata handling, original split order and a small training-to-scoring path. The training test runs one epoch of an unpretrained frozen-backbone ResNet-18 on synthetic images, reloads the checkpoint strictly and validates the resulting control predictions. These are software checks, not new earthworm performance estimates.

The public dataset checker validated 9,356 global metadata rows, all available photo paths, the original 6,191-image split assignments and both checkpoint hashes. The full classifier plan was generated in both the research environment and the clean environment. It contains 2,640 fits. Every removed-worm set in its 25 biological-control conditions matches the frozen study selections. Planning did not train those models.

In the clean environment, the public CLI classified one existing segmented photo from each acquisition stream, segmented one corresponding original photo per stream, generated both mask coordinate systems and scored the known labels at worm level. The supplied model files loaded and produced finite outputs. A single-example score is not a population benchmark.

Saved predictions and features from the preserved research package were reanalysed in separate local output folders using the existing research CPU environment. This included all 90 baseline runs, fixed-rank and adaptive-rank calibration across 30 seeds, all 750 matched-control prediction fits, visual rescoring, whole-worm bootstrap summaries, view/rank/donor checks, representation summaries, probability projections and historical biological results. The final vocabulary, biological-split and calibration/test checks passed. This test used saved artifacts omitted from the reduced public release; a new user must create them through training and inference.

The numerical comparison covers 1,587 rows: 54 baseline summaries, 33 domain differences, 144 visual summaries, 18 global calibration summaries, 1,302 calibration summaries and 36 matched-removal bootstrap contrasts. The compared means, seed SDs, gains and matched-bootstrap intervals agree with the saved reference at the recorded precision; maximum differences for those checked values were zero. `result_parity.json` records each table and column. This does not assert that every contextual number in the manuscript has been audited.

The five main publication layouts were generated as PDF and PNG using the fresh environment and regenerated result tables. All five PNG previews were inspected. Diagnostic plots were also generated from the saved-result analysis. Publication plotting source was adapted from the active manuscript's builders; provenance is in `figure_source_provenance.json`.

The validation did not retrain the 2,640 publication fits, repeat full neural inference over every photograph, run on a GPU or submit cluster jobs. Segmentation training was not rerun. Recreating the segmentation checkpoint requires its independent human annotations and original training partition, which are not in the reduced image release. Generated masks are not independent annotation evidence. No original experiments, datasets or manuscript files were changed, and nothing was uploaded or published.
